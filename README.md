# Portafolio Interactivo

## Descripción
Proyecto académico de la PC3 del curso Hojas de Estilo en Cascada Avanzado de la UTP. Demuestra el uso de Bootstrap 5, transformaciones CSS, animaciones y diseño responsivo.

## Tecnologías
- HTML5
- CSS3
- Bootstrap 5
- JavaScript

## Estructura
- `index.html`: estructura de la página.
- `css/styles.css`: estilos, transformaciones y animaciones.
- `js/script.js`: comportamiento del formulario y del menú móvil.

## Transformaciones 2D
- `rotate()`: gira la tarjeta Proyecto Creativo.
- `scale()`: aumenta el tamaño de la tarjeta Diseño Digital.
- `translateY()`: desplaza la tarjeta Desarrollo Web.
- `transition`: suaviza los cambios al pasar el cursor.

## Transformación 3D
Se utiliza `perspective`, `transform-style: preserve-3d`, `rotateX()` y `rotateY()` para crear un efecto de profundidad.

## Animaciones
- `@keyframes aparecer`: anima la entrada del título.
- `@keyframes girar`: hace girar el indicador de carga.
- `@keyframes ocultarLoader`: oculta el indicador después de un breve intervalo.

## Diseño responsivo
Se utiliza el sistema de cuadrícula de Bootstrap 5 y media queries para adaptar el diseño a pantallas pequeñas.

## Formulario
El formulario contiene Nombre, Email y Mensaje, además de los botones Enviar y Limpiar. La respuesta es una demostración: los datos no se envían a un servidor.

## Publicación
El proyecto está publicado mediante GitHub Pages.

## Ejecución local
Abre `index.html` en un navegador con conexión a Internet para cargar Bootstrap desde su CDN.
